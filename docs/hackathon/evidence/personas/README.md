# Execution evidence: five investor habits in the sandbox

Generated by `node tools/persona-runs.js` on 2026-10-19. Synthetic data only: no real person, account or trade. Each sandbox account is built with one known habit, its trades are exported as a broker CSV, imported through the app's own ledger parser and analysed by the same code the extension runs (`src/decisions.js`, `src/indicators.js`, `src/biases.js`).

## Notes for the reader

- First-hour impulse means a buy within an hour of the first recorded look at the stock (Stocktrails' definition), not the first hour after the market opens.
- The YOLO habit (oversized buys in turbulent markets) shows up as rules, not as a `detected` signal: turbulent stretches last weeks, and the calendar-shift test that guards the signal against that is deliberately strict. The coach offers it through its two turbulent-market rules, judged on later trades (see the robustness table).
- Each habit costs money against the NASDAQ; the account's other buys are set to beat it by about as much, so the average buy roughly matches the market. Otherwise skipping any buy would look like a good rule.
- Times in the CSV are UTC; the analysis reads hours in the local time zone of the machine that ran it.

## Reproduce, and show it in the app

```bash
node tools/persona-runs.js
```

```bash
node tools/sandbox.js
```

Then open `http://127.0.0.1:8780/?persona=fomo` (or `first_hour`, `night_trader`, `yolo`, `herd`) for the dashboard on that account. Each `trades.csv` can also be imported in My Habits > Trades & research as a generic CSV.
